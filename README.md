# CIDE (Custom Integrated Development Environment) 🚀

CIDE — это современная, легковесная и невероятно красивая кроссплатформенная интегрированная среда разработки (IDE), созданная на базе **C#** и **Avalonia UI**.

Разработанная с упором на эстетику, скорость и максимальный фокус, CIDE предлагает разработчикам "премиальный" опыт написания кода без тяжеловесности корпоративных IDE.

---

## ✨ Ключевые особенности

### 🎨 Кинематографичный Дизайн (Glassmorphism & Animations)
- **Fluid UI**: Плавные переходы (`CrossFade`), исчезающие панели и умный инерционный скролл.
- **Glassmorphism**: Использование полупрозрачных акриловых панелей, градиентов и стильных теней.
- **Zen Mode (F11)**: Одно нажатие — и все панели скрываются, оставляя вас наедине с кодом.

### ⚡ Быстрая Сборка C/C++
- Интегрированная система сборки `CompileService`, автоматически компилирующая проекты и отдельные `.c`/`.cpp` файлы с использованием MinGW (`gcc`/`g++`).
- **Умный скролл компилятора**: логи прокручиваются автоматически, но не мешают, если вы начали читать ошибки выше.
- **Стоп-кран**: Встроенная кнопка принудительной остановки (`Kill Process`) для зависших программ (например, при бесконечных циклах).

### 🗂 Мощный Файловый Менеджер
- Полноценное дерево файлов с поддержкой вложенности.
- Мини-тулбар и **Контекстное меню** (правый клик) для управления файловой системой:
  - 📄 Создать файл
  - 📁 Создать папку
  - ✏️ Переименовать (`F2`)
  - 🗑️ Удалить (`Delete`)
- Встроенные защитные окна подтверждений (`InputDialog`, `ConfirmDialog`).

### 📟 Продвинутый Терминал (Smart Terminal)
- Поддержка вкладок с интеграцией **PowerShell**, **CMD**, **WSL** и даже **SSH**!
- Терминал автоматически запускается в директории вашего проекта.
- Процесс терминала не умирает при переключении между вкладками.

### 🔍 Редактор Кода
- Разработано поверх `AvaloniaEdit`.
- **Живой поиск**: Мгновенная подсветка результатов прямо в тексте (полупрозрачный янтарный цвет) без засорения UI.
- Отображение текущей позиции курсора (Ln, Col) прямо в Status Bar.

## 🛠️ Технологический Стек

- **Язык**: C# (12.0)
- **Фреймворк**: Avalonia UI (v11)
- **Паттерн**: MVVM (через `CommunityToolkit.Mvvm`)
- **Редактор**: AvaloniaEdit
- **Терминал**: Iciclecreek.Terminal

## 🚀 Установка и Запуск

1. Убедитесь, что у вас установлен **.NET 8 SDK** (или новее).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/cide.git
   ```
3. Перейдите в папку проекта и запустите:
   ```bash
   cd cide
   dotnet run
   ```

## 🌐 Кроссплатформенность
Проект собирается и работает на **Windows**, **macOS** и **Linux**.
- Исполняемые файлы компилятора автоматически получают правильное расширение (`.exe` для Windows, без расширения для Linux/Mac).
- Все UI-элементы рендерятся силами Avalonia, гарантируя одинаковый внешний вид на всех платформах.
